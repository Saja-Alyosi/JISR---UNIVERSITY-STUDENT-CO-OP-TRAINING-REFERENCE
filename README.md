# 📘 JISR – Digital Cooperative Training Reference  
**Taif University – College of Computers and Information Technology**  

---

## 🎯 Project Overview  
**JISR** is an interactive, browser-based website designed to collect and organize co-op training reports and evaluations from various organizations. Its goal is to help students choose the best places for their practical training.

The site features a modern monochrome visual identity, works entirely offline, and requires no web server or internet connection.

## ⚡ System Requirements (Very Simple)
- ✔️ A modern web browser (Chrome, Firefox, Edge, Safari).
- ✔️ No internet connection required (all data is stored locally within the file).
- ✔️ No software installation or web servers needed.

---

## 🚀 How to Use (Quick Start)
1.  **Open the Website**  
    Double-click the `jisr_training_hub.html` file. It will open automatically in your default web browser.

2.  **Search and Filter**  
    - Type the company name or location into the *"Search for an entity"* field for instant filtering.  
    - Select a specific rating (Excellent, Average, etc.) from the dropdown menu.  
    - Click the *"Reset"* button to display all data again.

3.  **Read the Details**  
    Each company appears as a card containing: the name, location, training type, work hours, tasks, student comments, and a recommendation (Recommended / Not Recommended).

4.  **Live Statistics**  
    The numbers at the top of the page (Total Reports, Companies, Recommendations, and Excellent Ratings) update automatically based on your search and filter results.
